# 예시 자료 — 가상의 「○○시」

> **모두 지어낸 자료입니다.** 실제 기관·사람·문서와 관계없습니다. 스킬이 무엇을 찾아내는지 보이려고 **일부러 틀린 곳**을 넣었습니다.

## 입력 (`입력/`)

| 파일 | 내용 | 일부러 넣은 오류 |
|---|---|---|
| `등록정보_예시.xlsx` | 4개 부서, 2025년 생산 28건 | 등록번호 `6410001-0003` 중복 · `읍면 순회 간담회 결과` 단위과제 빈칸 · `축제 부스 배치도` 보존기간 '7년'(표준 아님)·쪽수 없음 · `보도자료 원고` 등록번호·공개구분 없음 |
| `간행물_예시.xlsx` | 간행물 3종 | `가을 축제 관광 안내` 미송부 · `예산 개요` 발간등록번호 형식 오류·송부 2부(3부 필요) |

열 이름은 [표준 열 이름](../docs/skills.md#열-이름이-안-맞을-때)대로 맞춰 두었습니다. 우리 기관 파일을 만들 때 본보기로 쓰세요.

## 써 보기

이 `입력` 폴더를 작업 폴더에 복사하고 Claude Code에서:

```text
입력 폴더 자료로 2025년 생산분 생산현황 통보서 만들어줘.
```

직접 실행하려면(저장소 최상위 폴더에서):

```bash
python plugins/records-skills/skills/production-status-report/scripts/run_all.py examples/입력 --year 2025 -o 산출/통보준비_2025
```

## 결과 (`결과예시/`)

위 명령으로 만든 결과 그대로입니다.

| 파일 | 먼저 볼 곳 |
|---|---|
| [`통보전_확인.md`](결과예시/통보전_확인.md) | **여기부터.** 고칠 것 8건과 제출 전 할 일 |
| `생산현황_2025.xlsx` | `고칠 것` 시트 |

| `간행물_점검.xlsx` | `점검` 시트 |
