## 1. 대학 보존기간 가이드 대조

**넣은 것** `가상대학_기준표.xlsx` — 단위과제 6개.

**일부러 넣은 오류**
- `학생증발급` 3년: 가이드의 `학생증관리`는 5년
- `자격증관리대장` 10년: 가이드는 준영구
- `전산시스템구축및개발` 10년: 가이드는 준영구
- `가상 축제 운영`: 가이드에 없는 기관 고유 과제

**결과** `대학가이드_대조.xlsx`
- 5과제를 맞췄고, 그중 3과제는 가이드보다 짧다고 표시합니다. 이름이 달라도 가이드의 '유사 단위과제'(학생증발급, 자격증관리대장)로 찾아 냅니다.
- '가이드에만 있는 과제' 시트에 기준표에 빠졌을 수 있는 196과제가 나옵니다.

## 3. 수해 피해 행정박물 응급조치

**넣은 것** `피해박물.xlsx`. 발견은 2026-07-15 09:00, 기준 시각은 이튿날 15:00입니다.

**결과** `행정박물_응급조치.xlsx`
- 처리 순서: 자개 장식이 붙은 목재 현판 → 염색 직물 제복(48시간 기한까지 남은 18시간) → 곰팡이 핀 액자(전문가 상의) → 도자기 → 금속 상패
- 도자기는 미세 분무기로 약하게 씻고, 깨진 조각은 하나씩 싸서 모읍니다. 관리번호 없는 액자에는 '포장재에 식별정보'를 적으라고 붙습니다.
- 상태조사표(손상 A~E·훼손도), 현장 체크리스트 12항목, 응급복구 키트 목록이 함께 나옵니다.

## 4. 보존 취약 종이기록물 예방조치

**넣은 것** `서고목록.xlsx` — 팩스 수신철, 트레이싱지·청사진 도면철, 720매 토지대장, 바스라진 회의록, 정상 철

**결과** `예방조치_계획.xlsx`
- 감열지 12면 → 간지 12장, 스테이플러 제거
- 도면철 → 청사진은 간지, 트레이싱지는 보호 폴더, 혼합 규격은 보호 보드·벨크로, 접힌 도면은 두꺼운 보호 폴더, 고무줄 제거
- 720매 토지대장 → 거대 편철 편철 개선, 120매 팩스철 → 100매 원칙 분철 검토

- 정상 철은 빠지고 '용품 준비' 시트에 수량 합계가 나옵니다.
