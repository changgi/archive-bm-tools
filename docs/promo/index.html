/plugin marketplace add changgi/archive-bm-tools
/plugin install records-skills@changgi-archive-bm-tools

Claude Code 안에서 입력합니다. 공개 저장소라 따로 권한을 받지 않아도 됩니다.

잠금은 세 겹, 결정은 사람에게

비밀기록물은 열지 않음

비밀 폴더의 읽기와 명령 실행을 훅이 막습니다. 비밀 관련 서식은 담당자가 비밀 전용 장비에서 직접 돌립니다.

원본은 읽기만

원본·보존 폴더에 쓰기를 막고, 결과는 언제나 새 파일로 씁니다. 차 있는 산출 폴더는 덮어쓰지 않습니다.

폐기·공개·제출은 사람이

스크립트는 후보와 초안까지 만듭니다. 폐기 집행, 공개 범위 변경, 메일 발송은 하지 않습니다.

처리 이력이 남음

어떤 도구가 언제 무엇을 했는지 로그로 남고, 산출물은 품질 관문(records-qa-gate)을 거칩니다.

30분이면 첫 결과까지

  1. Python 3.10 이상 설치

    python -m pip install openpyxl pypdf pikepdf pillow numpy python-docx "python-hwpx<7" holidays (Windows는 Git for Windows도)

  2. Claude Code 설치·로그인

    Windows irm https://claude.ai/install.ps1 | iex, macOS curl -fsSL https://claude.ai/install.sh | bash

  3. 저장소는 공개

    초대나 로그인 없이 받을 수 있습니다. 기관 방화벽이 막으면 gh auth login 뒤 다시 시도합니다.

  4. 플러그인 설치

    위 설치 명령 두 줄을 Claude Code에 입력하고 설치 범위는 Install for you (user scope).

  5. 작업 폴더 준비

    templates/의 CLAUDE.md와 .claude/settings.json을 작업 폴더에 복사합니다.

  6. 보호 장치 확인

    비밀/시험.txt 읽어줘라고 해 보고, 차단되면 정상입니다.
