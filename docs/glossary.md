# 용어 풀이

> 이 저장소에서 쓰는 IT 용어를 기록관리 담당자의 말로 풀었습니다.

[← 사용 안내로](README.md)

| 용어 | 쉬운 설명 | 비유 |
|---|---|---|
| **Claude Code** | 말로 시키면 파일을 읽고 프로그램을 돌려 일을 처리하는 AI 도구 | 말귀 밝은 새 직원 |
| **플러그인** | Claude Code에 끼워 넣는 기능 묶음. 이 저장소의 `records-skills` | 업무 매뉴얼 한 권 |
| **마켓플레이스** | 플러그인을 내려받는 목록(이 저장소 자체) | 매뉴얼을 받는 사내 자료실 |
| **스킬** | 한 가지 업무의 절차서 + 스크립트. 34종 | 매뉴얼의 한 장(章) |
| **스크립트** | 실제 계산·대조를 하는 작은 프로그램(.py) | 엑셀 매크로 |
| **Python** | 스크립트를 돌리는 프로그램 언어·실행기 | 계산기의 배터리 |
| **꾸러미(패키지)** | Python에 추가로 설치하는 부품(openpyxl 등) | 계산기의 추가 기능 |
| **터미널 / PowerShell** | 글자로 명령을 입력하는 창 | 전화 대신 쓰는 무전기 |
| **훅(hook)** | Claude가 무언가 하기 **직전·직후**에 자동으로 도는 검사 | 출입문 보안요원 |
| **settings.json** | Claude Code가 스스로 지키는 금지 규칙 파일 | 금고 자물쇠 |
| **CLAUDE.md** | 작업 폴더에서 Claude가 매번 먼저 읽는 원칙 | 책상 위 업무 수칙 |
| **저장소(repository)** | GitHub에 올린 파일 묶음과 변경 이력 | 버전별로 보관하는 문서철 |
| **비공개 저장소** | 초대받은 사람만 볼 수 있는 저장소 | 출입증이 필요한 자료실 |
| **PR(Pull Request)** | 바꾼 내용을 합치기 전에 검토받는 요청 | 결재 상신 |
| **병합(merge)** | 검토가 끝난 변경을 본선에 합침 | 결재 완료·시행 |
| **이슈(issue)** | 오류·요청을 적는 게시판 글 | 민원 접수 |
| **머리글(header)** | 엑셀 첫 줄의 열 이름 | 표의 제목 줄 |
| **xlsx / csv** | 엑셀 파일 / 쉼표로 구분한 표 텍스트 | 원본 장부 / 복사본 장부 |
| **HWPX** | 한글(한컴오피스) 문서의 개방형 형식 | 한글 파일 |
| **PDF/A** | 오래 보존하려고 글꼴까지 넣어 둔 PDF | 진공 포장 |
| **veraPDF** | PDF/A가 규격에 맞는지 공식 검사하는 프로그램 | 품질 인증 기관 |
| **SHA-256 해시** | 파일 내용으로 만든 고유한 지문(64자리). 한 글자만 바뀌어도 달라짐 | 지문 |
| **기준선(baseline)** | 처음 떠 둔 지문 목록 | 지문 대장 |
| **BagIt** | 파일 + 지문 목록 + 설명을 한 꾸러미로 묶는 국제 형식 | 봉인한 이삿짐 상자 |
| **WARC** | 웹페이지를 수집해 저장하는 국제 형식 | 웹 화면을 통째로 담은 상자 |
| **robots.txt** | 누리집이 "수집기는 여기 들어오지 마"라고 적은 파일 | 출입 금지 표지판 |
| **사이트맵** | 누리집의 모든 페이지 목록 | 건물 안내도 |
| **MBOX / EML** | 메일함 통째 / 메일 한 통 파일 | 우편함 / 편지 한 장 |
| **스키마** | 데이터베이스 표와 열의 설계 | 장부 양식 |
| **KST** | 한국 표준시(UTC+9) | |
| **exit 2** | 훅이 "막아라"라고 알리는 신호 | 보안요원의 정지 신호 |

## 기록관리 용어

이 저장소는 공공기록물법과 NAK 표준의 용어를 그대로 씁니다 — 생산·등록·분류·편철·정리·이관·평가·폐기·보존·공개·활용, 철/건, 단위과제, 보존기간, 공개구분(공개·부분공개·비공개). 비공개 사유는 「공공기관의 정보공개에 관한 법률」 제9조제1항 각 호(1~8호)를 함께 적습니다.
