# 기록매체 점검 (NAK 12:2022)

1. 관리대장 점검:
   `python "${CLAUDE_PLUGIN_ROOT}"/skills/media-check/scripts/media_inventory.py 매체대장.xlsx -o 산출/기록매체점검.xlsx`
   - 열: 매체번호, 매체종류, 용도(보존·임시·이관·백업), 수록일, 마지막점검일, 마지막되감기일, 용량, 사용량, 보호수단.
   - '조치 필요': 보존용 RW·RAM 광디스크(-R/+R만 허용), 반도체 1년 넘게 미점검, 플로피.
   - '주의': 사용률 80% 넘음, 테이프 3년 넘게 안 되감음·수록 10년 넘음, 점검 주기 지남(광디스크·하드디스크는 이 킷 기본 1년, `--check-years`), 보호수단 없음.
2. 간이 검사(부속서 D) — 매체 하나씩:
   `python "${CLAUDE_PLUGIN_ROOT}"/skills/media-check/scripts/media_verify.py E:/ 산출/매체검사/DVD-0012`
   - 매체는 읽기만 한다. 비어 있는 대상 폴더에 복사한 뒤 폴더 수·파일 수·크기와 파일별 SHA-256을 대조한다.
   - 복사가 지나치게 느리면(기본 2MB/s 미만) 배드섹터 등 물리 상태를 의심하고 복구 전문가 자문을 권한다.
   - '이상 없음'은 검사 시점에 한한다. 결과 CSV를 매체 대장 점검일 근거로 남긴다.
3. 하지 않는 것: 매체 포맷·덮어쓰기·폐기, 쓰기방지 해제. 폐기는 disposal-dossier의 매체별 폐기 방법을 따른다.
