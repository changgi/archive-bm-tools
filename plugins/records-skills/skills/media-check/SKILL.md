# 기록매체 점검 (NAK 12:2022)

1. 관리대장 점검:
   `python "${CLAUDE_PLUGIN_ROOT}"/skills/media-check/scripts/media_inventory.py 매체대장.xlsx -o 산출/기록매체점검.xlsx`
   - 열: 매체번호, 매체종류, 용도(보존·임시·이관·백업), 수록일, 마지막점검일, 마지막되감기일, 용량, 사용량, 보호수단.
   - '조치 필요': 보존용 RW·RAM 광디스크(-R/+R만 허용), 반도체 1년 넘게 미점검, 플로피.
   - '주의': 사용률 80% 넘음, 테이프 3년 넘게 안 되감음·수록 10년 넘음, 점검 주기 지남(광디스크·하드디스크는 이 킷 기본 1년, `--check-years`), 보호수단 없음.
2. 간이 검사(부속서 D) — 매체 하나씩:
   `python "${CLAUDE_PLUGIN_ROOT}"/skills/media-check/scripts/media_verify.py E:/ 산출/매체검사/DVD-0012`
   - 매체는 읽기만 한다. 비어 있는 대상 폴더에 복사한 뒤 폴더 수·파일 수·크기와 파일별 SHA-256을 대조한다.
   - 복사가 지나치게 느리면(기본 2MB/s 미만) 배드섹터 등 물리 상태를 의심하고 복구 전문가 자문을 권한다.
   - '이상 없음'은 검사 시점에 한한다. 결과 CSV를 매체 대장 점검일 근거로 남긴다.
3. 하지 않는 것: 매체 포맷·덮어쓰기·폐기, 쓰기방지 해제. 폐기는 disposal-dossier의 매체별 폐기 방법을 따른다.

## 광디스크 오류율 판정
`python "${CLAUDE_PLUGIN_ROOT}"/skills/media-check/scripts/disc_errors.py 측정목록.xlsx [--standard iso|china] -o 산출/광디스크_오류율.xlsx`
- 오류율 검사 장비로 잰 값(DVD PI sum 8, BD R-SER·Burst, CD BLER, 수정 불가능 오류)으로 등급과 다음 검사일을 낸다.
- DVD: 초기 100 미만 양호(중국 80), 정기 140 미만 계속 보존·140~280 빠른 이전·280 이상 즉시 이전, 정기 검사 3년(더 짧게 권장). `--standard china`면 140/180/240과 주기 2년→1년→6개월.
- BD: 초기 R-SER 3.5E-4·Burst 800바이트, 정기 5E-4/1E-3·800/1,900바이트. CD: BLER 220이 읽기 한계(50·220 구간은 스크립트가 정한 값).
- 수정 불가능 오류가 하나라도 있으면 즉시 이전하고 소실 데이터를 확인한다. 장비마다 값이 다르므로 같은 장비로 추세를 본다.
- 근거: 국가기록원 「전자기록물 이관·보존 매체의 기준 설정 및 규격화 연구」 표 15~17(ISO/IEC 29121, JIS Z 6017, DA/T 38-2008, JIIMA BD-R 기준 정리).
- 수록 품질: 국가기록원 「Blu-ray Disc의 최적 매체수록 기술 및 도구 고도화 방안 연구개발」은 드라이브별 기록 방식(Write Strategy)이 수명을 좌우하고, '저속 CLV가 더 안정'이라는 통념과 달리 CAV 기록도 뒤지지 않았다고 보고했다. 배속보다 수록 직후 오류율 초기 검사(위 기준)로 매체·드라이브 조합을 확인한다.
