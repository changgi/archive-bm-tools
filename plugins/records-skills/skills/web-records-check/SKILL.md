# 웹기록물 수집 준비 점검

1. 누리집: `python "${CLAUDE_PLUGIN_ROOT}"/skills/web-records-check/scripts/web_readiness.py --url https://www.기관.go.kr --max-pages 40 -o 산출/웹기록물_점검.xlsx`
   - 같은 호스트만, 정해진 쪽수만, 0.5초 간격으로 읽는다. 기관 자기 누리집에만 쓴다.
2. WARC(기관이 `wget --warc-file` 등으로 직접 수집한 것): `--warc 수집본.warc.gz` — WARC-Block/Payload-Digest 대조, 오류 응답만 담긴 쪽.
3. SNS·블로그: `--channels 채널목록.xlsx`(채널명·주소·운영부서·개설일·종료일·수집일) — 운영부서 없음, 운영 종료 전에 수집 안 함, 연 1회 주기.
4. '고칠 것'을 담당자에게 알린다. 누리집 전체 robots 차단은 지침상 하면 안 된다(개인정보 등 일부 경로만 제외, 공공데이터법 제3조③). 연결 실패가 많으면 수집 로봇 IP 예외처리를 요청한다.
5. 하지 않는 것: robots.txt·누리집 수정, 국가기록원 수집 협의·IP 예외 등록, 다른 기관 누리집 수집.

알아 둘 한계: 화면을 스크립트로 그리는 누리집은 링크 수와 script 수로 '의심'만 표시한다. 실제 재현 여부는 국가기록원 수집본이나 WARC 재생기로 본다.

근거: 공공기록물법 시행령 제2조 10호, 제46조의2(2025.5.20. 신설, law.go.kr 2026-11-20 확인), 국가기록원 「2026년 기록물관리 지침」 웹기록물(시행령 제46조의2 반영)(수집 범위·주기·WARC/K-WARC·기관 협조사항·FAQ).
