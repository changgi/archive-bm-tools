# 단위과제·보존기간 후보

1. `python "${CLAUDE_PLUGIN_ROOT}"/skills/task-suggest/scripts/suggest_task.py 목록.xlsx --common 중앙행정기관 -o 산출/단위과제_후보.xlsx` (기관 기준표가 있으면 `--criteria`)
2. 1순위 후보와 현재 보존기간이 다르면 '확인'으로 표시된다. 업무설명·책정사유 열을 근거로 담당자에게 확인을 요청한다.
3. '후보 약함'은 제목만으로 알 수 없는 것이다. 억지로 고르지 않는다.
4. 보존기간 확정은 처리과·기록관이 하고, 관할 영구기록물관리기관과 협의한다(시행령 제26조③).

데이터: retention-review/assets/common/common_task_criteria.csv — 국가기록원 누리집 기록물 분류기준의 공통업무 보존기간 준칙 xlsx 7종을 한 표로 합친 것(2026-11-20 받음). 새 판이 나오면 다시 만든다. retention-review의 `--common 기관유형`도 같은 표를 쓴다.
