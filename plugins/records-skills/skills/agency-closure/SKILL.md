# 한시·폐지기관 기록물 인계인수 (NAK 15:2021)

1. `python "${CLAUDE_PLUGIN_ROOT}"/skills/agency-closure/scripts/closure_handover.py 기록물목록.xlsx --type 폐지-승계없음 --org "○○위원회" --to "○○기록원" --done 2026-12-15 -o 산출/인계인수.xlsx`
   - 유형: 통합 · 한시 · 폐지-승계 · 폐지-승계없음 · 일부승계 · 공공기관전환 · 민간전환.
2. 결과:
   - '요약': 유형별 관리 주체와 조치(5장).
   - '이관목록-문서·시청각·행정박물(부속서 C)': 확인할 것(보존기간·비공개 사유·저작권 동의 빈칸).
   - '인계인수서(부속서 B)': 유형별 수량(문서 철·카드·도면·사진 점·시청각 매체·행정박물), 인계자·인수자·입회자 서명 칸.
   - '체크리스트(부속서 A)': A.1 사전 조치 ~ A.5 인수 후.
   - '일정': 인계계획 통보(인계 착수 전), 인계인수서 사본·인수 목록 통보(인수 종료 + 3개월), 공공기관 전환 시 30년 이상 이관 연도.
3. 꼭 알릴 것:
   - 승계기관이 없으면 보존기간에 관계없이 일체를 관할 영구기록물관리기관으로 이관한다. 10년 이하도 영구기관과 협의 없이 폐기하지 않는다.
   - 처리과 사무실 보유 기록물의 임의 폐기 금지를 먼저 고지한다.
   - 인계 뒤 업무 참고용으로 쓰는 것은 '사본' 처리한다.
4. 하지 않는 것: 공문 발송, 인계인수 실행, 폐기.
