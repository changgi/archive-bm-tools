# 목록 작성·디지털화 사업 검수 (NAK 23:2017)

1. `python "${CLAUDE_PLUGIN_ROOT}"/skills/listing-qa/scripts/listing_qa.py 색인목록.xlsx --images 스캔폴더 --sample 3 --checked 2000 --errors 1 -o 산출/목록검수.xlsx`
   - 색인목록 열: 철관리번호(레이블번호), 철제목, 권호, 보존기간, 등록번호, 건제목, 생산일자, 시작쪽, 끝쪽(또는 쪽수), 작업자, 작업일.
   - 스캔 이미지는 '등록번호' 이름의 폴더 또는 '등록번호_쪽' 파일로 센다.
2. '검수 결과'의 '고칠 사람'대로 돌려보낸다. 검증 담당자가 직접 고치지 않고 작업자가 고치게 한다(5.4.1).
3. '표본': 작업자·작업일별로 3% 이상(시드 고정이라 같은 표본을 다시 뽑을 수 있음). 검사 결과 칸을 채워 '품질 수준'에 넣는다(통상 99.9%).
4. '서식 목록': 반출·반입서(records-forms carry), 인수·인계서, 예외처리 요청·협의서, 교정확인서, 검사확인서, 보안 실태점검(월 1회).
5. 하지 않는 것: 기록물 원본 열람, 시스템 업로드.

## RAMP 일괄등록 파일 (기록물통합서비스플랫폼 일괄등록 규격 2024. 10.)
`python "${CLAUDE_PLUGIN_ROOT}"/skills/listing-qa/scripts/ramp_batch.py 일괄등록서식_채움.xlsx --registrar 부서코드,직위,이름,ID [--encoding cp949] -o 산출/RAMP일괄등록/`
- 빈 서식: `assets/RAMP_일괄등록_서식_2024.xlsx`(국가기록원 표준·지침·매뉴얼 > 규격·서식). '철 등록부'·'기록물등록대장'(+특수목록·전자파일) 시트를 채운다.
- 결과: DOCU.TXT(철 43칸)·DETAIL.TXT(건 53칸)·SPECIAL.TXT·FILE.TXT(Tab 구분, 입력항목 순서), '일괄등록_점검.xlsx'.
- 점검: 필수 빈칸, 칸 길이, 코드값(보존기간 01~40·보존장소·열람조건·등록구분 등), 철분류번호 28자리·중복, 보존기간과 보존장소(30년 이상은 2), 비치종결일자·비치사유 짝, 구기록물 단위업무코드 99999999, 건 분류번호가 철에 있는지, 생산(접수)등록번호 13자리, 공개여부 9자리와 사유 Y/N, 철 등록건수·쪽수 = 건 합계.
- 사람이 쓰는 값도 받는다(영구 → 40, 1 → 000001). 비밀분류 3급 이상 행은 파일에서 뺀다. 업로드 인코딩은 규격에 없으니 기관 RAMP에서 확인한다.
