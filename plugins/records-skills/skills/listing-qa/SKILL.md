# 목록 작성·디지털화 사업 검수 (NAK 23:2017)

1. `python "${CLAUDE_PLUGIN_ROOT}"/skills/listing-qa/scripts/listing_qa.py 색인목록.xlsx --images 스캔폴더 --sample 3 --checked 2000 --errors 1 -o 산출/목록검수.xlsx`
   - 색인목록 열: 철관리번호(레이블번호), 철제목, 권호, 보존기간, 등록번호, 건제목, 생산일자, 시작쪽, 끝쪽(또는 쪽수), 작업자, 작업일.
   - 스캔 이미지는 '등록번호' 이름의 폴더 또는 '등록번호_쪽' 파일로 센다.
2. '검수 결과'의 '고칠 사람'대로 돌려보낸다. 검증 담당자가 직접 고치지 않고 작업자가 고치게 한다(5.4.1).
3. '표본': 작업자·작업일별로 3% 이상(시드 고정이라 같은 표본을 다시 뽑을 수 있음). 검사 결과 칸을 채워 '품질 수준'에 넣는다(통상 99.9%).
4. '서식 목록': 반출·반입서(records-forms carry), 인수·인계서, 예외처리 요청·협의서, 교정확인서, 검사확인서, 보안 실태점검(월 1회).
5. 하지 않는 것: 기록물 원본 열람, 시스템 업로드.
