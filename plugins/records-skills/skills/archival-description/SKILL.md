# 기록물 기술 점검 (NAK 13:2022)

1. `python "${CLAUDE_PLUGIN_ROOT}"/skills/archival-description/scripts/description_check.py 기술목록.xlsx -o 산출/기술점검.xlsx`
   - 열: 참조코드, 상위참조코드, 제목, 일자, 기술계층, 생산자명, 범위와내용, 규모, 종류.
2. '점검 결과'의 '고쳐 쓸 값'은 제안이다(예: 단기4293년 → 1960, 철의 1960/03/01-1960/12/31 → 1960-1960). 연호는 추가설명(주기)에 남긴다.
3. 범위와 내용 서술의 정확성, 행정연혁·색인어 같은 선택요소는 기술 담당자가 판단한다.
4. 기록관이 수집 기록·행정박물·기증 컬렉션 검색도구를 만들 때, 영구기록물관리기관과 기술정보를 주고받을 때 쓴다.
