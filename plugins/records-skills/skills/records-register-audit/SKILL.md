# 기록물 정리 점검

1. `python "${CLAUDE_PLUGIN_ROOT}"/skills/records-register-audit/scripts/register_audit.py 등록정보.xlsx 실물점검표.xlsx --key 철분류번호 -o 산출/정리점검.xlsx`
2. 순서대로 보고한다: 미등록 실물 → 실물 없음 → 쪽수 불일치 → 등록번호 표기 없음 → 공개·비밀 점검 → 상자 혼재.
3. 비밀 표시 행은 번호에 '(비밀 표시)'만 붙고 제목은 결과에 나오지 않는다. 비밀 여부 판단은 담당자에게 넘긴다.
4. 고칠 것은 처리과가 전자기록생산시스템에서 고친다. 정리 결과는 등록정보에 반영해야 하고(시행령 제24조②), 생산현황은 그 뒤에 작성한다(시행규칙 제21조).
5. 정리 기한: 12월 31일까지 생산·접수 완결, 다음 해 2월 말일까지 공개여부·접근권한 재분류, 분류·편철 확정(시행령 제24조①).
