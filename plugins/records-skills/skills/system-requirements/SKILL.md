# 시스템 기능요건 점검

1. 빈 점검표: `python "${CLAUDE_PLUGIN_ROOT}"/skills/system-requirements/scripts/req_checklist.py --system 기록관리시스템 -o 산출/기능요건_점검표.xlsx`
   - 시스템: 기록관리시스템(NAK 6, 161개) · 영구기록관리시스템(NAK 7, 220개) · 정부산하(NAK 20, 149개, CM 포함) · 생산시스템(NAK 19-1, 83개) · 전자문서시스템(NAK 19-2, 76개) · 업무관리시스템(NAK 19-3, 73개).
   - 필수만 보려면 `--only-m`.
2. 기관·사업자가 '이행'(충족·부분·미충족·해당없음)과 '근거'(화면·문서·시험 결과)를 채운다.
3. 결과: `... --results 채운점검표.xlsx -o 산출/기능요건_결과.xlsx` → '요약'(필수 충족률, 장별 집계), '필수 미충족'.
4. 쓰는 곳: 시스템 구축·고도화 과업지시서의 요구사항, 감리·검수, 기관평가의 시스템 지표 증빙.
5. 주의: 요건 문장은 PDF에서 옮긴 원문이다(줄바꿈 때문에 띄어쓰기가 붙은 곳이 있음). NAK 19-1·19-2는 원문에 M/O 표시가 없어 '~하여야 한다'를 필수, '~할 수 있다'를 선택으로 나눴다. 판단이 갈리면 원문 PDF로 확인한다.
