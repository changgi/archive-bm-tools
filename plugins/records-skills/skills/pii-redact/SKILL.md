# 개인정보 탐지

1. `python "${CLAUDE_PLUGIN_ROOT}"/skills/pii-redact/scripts/pii_scan.py 대상(파일 또는 폴더) -o 산출/개인정보_탐지.csv`
2. 결과 CSV에는 값을 가린 형태만 있다. 원문 값을 대화나 다른 파일에 옮겨 적지 않는다.
3. 탐지 0건이어도 "개인정보 없음"이라고 말하지 않는다. 이름·주소·병력처럼 패턴이 없는 개인정보는 사람이 확인해야 한다고 알린다.
4. 가림본(PDF 가림 처리)은 사람이 범위를 확인한 뒤 만든다. 원본은 그대로 둔다.

## 개인정보가 들어 있는 기록물을 지울 때 (국가기록원 「2026년 기록물관리 지침」 부록 1(2024년판 부록 7과 같은 내용))
- 공공기록물로 등록된 기록물은 개인정보 보유기간이 지나도 그 기록물의 보존기간까지 관리하고, 공공기록물법 평가·폐기 절차(시행령 제43조)로만 없앤다. 개인정보보호법 제21조의 '즉시 파기'를 등록된 기록물에 적용하지 않는다.
- 공공기록물법 관리 대상이 아닌 개인정보(예: 업무PC에 남은 개인정보 파일 사본)는 개인정보보호법에 따라 보유기간이 지나면 파기한다.
- 이 스킬은 찾아 가리는 일만 한다. 어느 쪽에 해당하는지 판단과 파기는 담당자가 한다.
