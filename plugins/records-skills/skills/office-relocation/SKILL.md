# 청사 이전 대비 기록물 이송·재배치 (국가기록원 「공공기관 청사 이전 대비 기록관리 업무 매뉴얼」)

1. `python "${CLAUDE_PLUGIN_ROOT}"/skills/office-relocation/scripts/relocation_plan.py 보유현황목록.xlsx --year 2026 --per-box 10 [--org 기관명] -o 산출/청사이전.xlsx`
   - 목록 열: 부서(처리과), 기록물철 제목, 생산연도, 보존기간, 보관위치(사무실·문서고), 권수(없으면 1)·쪽수, 비밀구분(있으면).
2. 결과 시트
   - 보유현황 통계: 부서 × 보존기간, 보관위치별 권수.
   - 보존기간 확인: 보존기간 빈칸·표기 이상 → 처리부서 의견조회 대상.
   - 평가·폐기 후보: 생산연도 + 보존기간이 지난 것(영구·준영구 제외). 이송 전에 평가 절차(disposal-dossier)를 밟고, 폐기가 정해지지 않은 것은 임의 폐기하지 않는다.
   - 관리번호·레이블: 생산부서 → 생산연도 → 보존기간 순으로 정렬해 관리번호, 보존기간표 레이블(관리번호·생산부서명·생산연도·보존기간).
   - 이송 박스: 같은 부서·보존기간끼리 `--per-box`권씩 박스번호를 매기고, 박스별 목록(동봉용)과 박스 인식 스티커 문구.
   - 배가표: 신청사 서고 서가 번호 칸(비움) — 서가 번호와 박스 번호를 맞춰 배가한 뒤 실물 대조.
   - 추진상황 점검표: 기본계획 → 보유현황 → 평가·폐기 → 이송·재배치 → 설계·시공 → 기록관 설치·운영 6영역(준비·진행·완료 칸).
   - 박스 라벨: 지방이전 지침 예시대로 박스번호(00001)·권수·생산부서·관리번호 범위, 박스별 목록 1부 동봉.
   - 신청사 서고 산정: 현재 보유량 + 최근 5년 연평균 생산 × `--growth-years`(기본 10)를 140%로 키운 필요 수용량, 이동식 서가 면적 50% 감축·하중(고정 750, 이동 1,000~1,200kgf/㎡), 비밀 전용서고, 소요예산 유형(A~D, 2011 예시).
   - 이전비용 견적 점검: 운반임·작업임·포장정리·옵션비·포장재료 줄에 수량·단가를 넣으면 소계·관리경비 5%·기업이윤 10%·부가세 10%·천 원 절사 합계가 수식으로 계산된다(지침 참고 1, 예시 단가는 참고 칸에만).
3. 꼭 알릴 것
   - 이전 과정에서 무단 폐기·훼손·누락이 없도록 처리과 사무실 보유 기록물의 임의 폐기 금지를 먼저 알린다.
   - 이송 차량에는 직원이 함께 탄다(선탑). 박스 번호와 서가 번호를 맞추고, 해포 후 기록물철 목록과 실물을 대조한다.
   - 전자문서시스템은 이전 전에 사전조사하고, 데이터 훼손에 대비해 복제한다(정보화 부서).
   - 기록물·일반자료를 폐기할 때는 보안 준수사항(파쇄·입회·개인정보 노출 방지)을 지킨다.
   - 비밀구분이 있는 철은 목록에 옮기지 않고 건수만 세어 담당자에게 넘긴다.
4. 하지 않는 것: 폐기 실행, 이송 실행, 공문 발송.
