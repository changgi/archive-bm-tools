# 행정박물 점검

1. `python "${CLAUDE_PLUGIN_ROOT}"/skills/admin-artifacts-check/scripts/artifacts_check.py 행정박물목록.xlsx --asof 2025-12-31 -o 산출/행정박물_점검.xlsx`
2. '점검' 시트에서 고칠 것을 보고한다: 기본정보 11항목 빈칸, 등록번호 형식(처리과코드7+연도4+일련번호6)·중복, 유형(별표 4의 7개), 재질(13종), 관인류 폐기공고번호, 공직자선물 수령인·수령일·증정인·수령경위.
3. '이관 기한' 시트는 이관대상('이관')으로 지정된 것만 본다. 관인류·상징류·기념류·사무집기류는 사건(폐기·폐지·행사 종료·활용 종료)이 기준이라 '사유발생일' 열이 있어야 기한을 정한다. 기한이 지났으면 이관하거나 영구기록물관리기관과 연장을 협의한다(시행령 제57조⑤).
4. '서식 5 수치'·'서식 6 행'은 기준일에 기록관이 보유한 것(이관일이 기준일 이전인 것 제외)이다. `production-status-report`의 `fill_official_form.py --artifacts 산출/행정박물_점검.xlsx`로 통보서식에 옮긴다. 없으면 서식 5는 0, 서식 6은 '해당없음'.
5. 하지 않는 것: 관리대상 선별(선별 체크리스트 7기준 점수는 처리과·기록관이 매김), 이관대상 지정(영구기록물관리기관), 폐기(시행령 제43조① 절차).

- 유형·재질이 비어 있으면 행정박물명·내용요약으로 후보를 적는다(국가기록원 「행정박물 상태검사·점검 원내 실무 매뉴얼」 2019의 형태 17종·재질 세부 범위: 관인·우표·상패·현판·깃발·집기 등 → 유형, 청동·목재·직물·아크릴 등 → 재질). 후보일 뿐이고 대표 재질은 2026 지침 13종 중 하나를 고른다. 수량은 '점' 단위, 생산 때부터 있던 보존용기·증정 메시지카드만 수량에 넣는다(같은 매뉴얼).

근거: 공공기록물법 제24조, 시행령 제57조·별표 4·별표 5(law.go.kr 2026-11-19 확인), 국가기록원 「2026년 기록물관리 지침」 행정박물 관리와 붙임 관리카드, 2024년 생산현황 통보서식 서식 5·6 기재요령. 일자: 관리카드 작성방법은 yyyy-mm-dd, 서식 6은 yyyymmdd라 서식 6 행은 yyyymmdd로 쓴다.
