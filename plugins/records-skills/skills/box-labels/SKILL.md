# 보존상자 편성·표지

1. `python "${CLAUDE_PLUGIN_ROOT}"/skills/box-labels/scripts/box_labels.py 기록물철목록.xlsx --org "○○시 기획과" --prefix 2025- -o 산출/보존상자`
   - `--box-pages`: 상자 하나에 넣을 최대 매수. 기본 1000이고, 기관 상자 규격에 맞게 바꾼다.
   - PDF에 한글 글꼴을 넣으려면 `--font C:/Windows/Fonts/malgun.ttf`(Windows는 자동으로 찾음). 글꼴이 없으면 HTML을 브라우저로 인쇄한다. 인쇄 설정은 배율 100%, 여백 없음.
2. 결과:
   - `보존상자_편성안.xlsx`: 상자번호별 철 목록, 매수 합계.
   - `확인할 것` 시트: 100매 초과 철, 생산연도·보존기간 빈칸, 쪽수 없음.
   - `보존상자_표지.pdf`·`.html`: 상자 측면에 붙일 표지.
3. 100매가 넘는 철은 분권한다. 같은 제목·분류번호로 나누고 권호수만 다르게 하며, 전자기록생산시스템의 등록정보도 함께 고친다(사람이 함). 분권한 뒤 다시 돌린다.
4. 이관할 때는 `transfer-reconcile`의 이관목록(별지 제2호)과 상자번호를 맞춘다.
5. 하지 않는 것: 실물 상자 배치, 시스템 등록정보 수정. 상자 규격(별표 5: 중성판지 800g/㎡ 이상·두께 1㎜ 이상)은 구매 때 확인한다.

## 근거 (law.go.kr 2026-11-20 확인)

| 규정 | 내용 |
|---|---|
| 시행규칙 제9조③ | 철당 100매 이내, 넘으면 2권 이상으로 나누고 같은 제목·분류번호에 권호수만 다르게 |
| 제9조④ | 완결 문서는 별표 4 보존용 표지 + 별표 5 보존상자에 단위과제별로 |
| 제9조⑤·별표 6 | 상자 측면에 보존상자 표지: 가로 9㎝(항목 3 + 내용 6), 세로 7.5㎝(상자번호 1.5 · 생산연도 1.5 · 생산기관 1.5 · 업무명 3.0) |
| 제14조② <신설 2026. 9. 11.> | 기록물철을 생산연도별·보존기간별로 구분해 보존상자에 넣음 |
| 시행령 제32조⑤ | 비전자기록물 이관은 단위과제별로 보존상자에 넣어 이관목록과 함께 |
