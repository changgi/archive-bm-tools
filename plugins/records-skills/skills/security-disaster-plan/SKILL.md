# 보안·재난관리 대책 점검 (NAK 2-1:2024)

1. 실행:
   `python "${CLAUDE_PLUGIN_ROOT}"/skills/security-disaster-plan/scripts/sd_plan.py --org 기록관 --risk 위험평가.xlsx --staff 임무카드.xlsx --supplies 비상용품.xlsx --last-review 2025-11-01 -o 산출/보안재난.xlsx`
   - 입력은 모두 선택이다. 없으면 빈 서식(위협 12종, 비상용품 예시)을 만든다.
   - 안전규칙을 업무별로만 뽑으려면 `--work 서고관리,상태검사`.
   - 영구기록물관리기관은 `--org 영구 --bia 업무영향.xlsx`(업무프로세스·RTO(시간)·RPO) → 전자기록물 7장 점검과 Tier·DR 모델.
2. 보고 순서:
   - 보안대책 연 1회 검토가 지났는지('보안 체크리스트' 마지막 줄).
   - '위험평가표': 점수(발생가능성 × 위험도) 높은 순. 15점 이상은 점검 강화, 대책이 비었으면 표시. 구간(15·8)은 이 킷의 기본값이다.
   - '임무카드': 재난 시 반·업무·대행·휴대폰 빈칸.
   - '비상용품 대장': 수량 0, 위치 없음, 유통기한 지남·30일 안.
3. 나머지 시트('재난관리 체크리스트', '안전규칙(표 2)', '대응·복구 계획 항목', '재난 보고서(6.6.4)')는 담당자가 채운다.
4. 연결: 대피 우선순위·응급복구는 `disaster-recovery`, 필수기록물은 `vital-records`, 서고 점검은 `stack-environment`.
5. 하지 않는 것: 위험 점수·임무 배정 결정, 보호구역 지정, 보안장비 설정 변경, 신고. 비밀기록물 목록은 열지 않는다.
