# 4대 속성 점검 기준

근거: 공공기록물법 시행령 제4조(기록물의 진본성·무결성·신뢰성 및 이용가능성 보장).

| 속성 | 이 스킬의 점검 | 실패 예 |
| --- | --- | --- |
| 진본성 | 관리번호별 생산기관·생산일자가 원본 목록과 같은가 | 정리 중 생산일자가 바뀜 |
| 무결성 | 파일 SHA-256이 manifest와 같은가 | 변환·복사 중 파일 손상 |
| 신뢰성 | 판단마다 근거(기준표 항목·법 조문·원문 위치)가 있는가 | 보존기간을 근거 없이 제안 |
| 이용가능성 | 필수 메타데이터, 공개구분 값, 비공개 사유(정보공개법 제9조 1~8호 + 구체 사유), 공개 행의 개인정보 | '비공개'인데 사유 칸이 '5호'뿐 |

비공개·부분공개는 호수와 구체적 사유를 함께 적고, 개인정보가 일부만 있으면 부분공개로 처리한다(온나라 공개여부 설정 안내 등 기관 지침).
