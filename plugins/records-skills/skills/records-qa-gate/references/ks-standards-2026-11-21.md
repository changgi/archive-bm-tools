# 국가기록포털 '한국산업표준(KS)' 12종 — 공개 자료로 확인한 범위와 스킬 대응 (2026-11-21 KST)

KS 원문은 유료다(한국표준협회 e-나라표준인증). 그래서 원문은 옮기지 않았다. 아래 내용은 ISO 공식 초록, DIN·ANSI·Standards Australia의 공개 목차, 국내 학술지에서 확인한 범위·구성·변경 이력이다. 스킬에는 원문 문장을 넣지 않았고, 구성(절 번호·제목)과 개념만 우리 말로 적어 작업지·점검표 칸으로 썼다.
목록은 standardList.do 탭에서 가져왔고, 새 KS가 올라오면 `source_watch.py`가 'KS:' 항목으로 알린다.

## 공개로 확인한 출처
- ISO 공식 초록: 21946(iso.org/standard/72274), 26122(43391), 13028(52391), 16175-3(55792, 철회 표시)
- DIN 공개 목차: ISO/TR 21946:2018, ISO/TR 26122:2008, ISO 16175-3:2010, ISO 30301:2019
- KS 목록·제정 연도: 국가기록포털 standardList.do, 위키독스 기록관리 표준 정리
- 15489 기록 특성: 한국기록관리학회지 등(설문원 2005 외)

## 이 조사로 새로 만든 것
- `records-schedule-check/scripts/appraisal_worksheet.py` — TR 26122·TR 21946 절 구성을 칸으로 옮긴 업무과정 분석·평가 작업지, 그리고 record-by-design `sweep`에 바로 넣을 기록화설정 초안
- `records-qa-gate/scripts/source_watch.py` 출처에 KS 목록(standardList.do) 추가 — KS 번호가 늘거나 바뀌면 알림
