# 공개 재분류 기준 (2026-11-19 확인)

| 분류 | 기준 | 근거 |
| --- | --- | --- |
| 이관 시 분류 | 기록물은 이관할 때 공개여부를 분류해 이관 | 공공기록물법 제35조, 시행령 제72조~제74조 |
| 5년 주기 | 비공개 기록물은 5년 주기로 공개여부 재분류 | 법 제35조제2항 |
| 30년 경과 | 비공개 기록물은 생산 30년 경과 시 공개 원칙. 비공개 기간 연장은 기록물공개심의회 심의 | 법 제35조제3항·제4항 |
| 6호 유예 | 정보공개법 제9조제1항제6호(개인정보)로 비공개 재분류한 기록물은 생산연도 종료 후 30년까지 재분류를 하지 않을 수 있음 | 법 제35조제1항 단서(2019.12.3. 개정) |
| 비밀기록물 | 비밀기록물 재분류와 해제된 비밀의 공개여부는 별도 절차 | 시행령 제68조제6항·제70조제2항 |

출처
- 서울기록원 기록물공개심의회 운영 규정(안)·운영 규정 — 5년 주기, 30년 공개 원칙, 심의 대상
- 「지능형 아카이브 솔루션을 활용한 공개재분류 연구」(2021) — 제35조제1항 단서(6호) 인용
- 국가기록원 소식지 vol.171(2026) — 비공개 기록물 174만여 건 공개 전환, 전자(화) 기록물 112만여 건에 AI로 개인정보 확인

주의: 기준 연도 계산("생산연도 종료 후 30년")은 기관 지침에 맞는지 확인할 것. 이 스크립트는 '기준 연도 − 생산연도 > 30'을 30년 경과로 본다.

## 2026-11-20 국가법령정보센터 원문 확인
- 시행령 제72조① 재분류해 이관할 때 건 단위 또는 쪽 단위로 공개여부를 구분하고, 비공개는 사유를 함께 제출한다.
- 시행령 제72조③ 비공개 기간 연장이 필요한 공공기관의 장은 연장시기·사유를 해당 비공개기록물 보존기간 기산일부터 30년이 지난 해의 전년도 말까지 영구기록물관리기관에 제출한다. → 생산(종료)연도 py의 기록물은 py+30년 12월 31일까지. 도구의 '연장 신청 기한' 시트.
- 시행령 제72조④ 정보공개 청구로 생산기관 의견을 조회하면 생산기관은 7일 이내 의견 제출, 비공개 의견에는 사유와 공개가능 시기를 포함한다.
- 시행령 제27조 공개여부는 건 단위로 구분해 등록정보로 관리한다.
