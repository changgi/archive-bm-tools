# 학교기록물 점검 (2025년 학교기록물 관리 지침)

1. `python "${CLAUDE_PLUGIN_ROOT}"/skills/school-records/scripts/school_check.py 등록목록.xlsx --today 2026-03-02 -o 산출/학교기록물_점검.xlsx`
   - 열: 건명, 생산일자, 단위과제, 전자구분, 이관일자, 이관연장(Y), 비치(Y), 공개구분, 처분(있으면).
2. '점검' 시트 — 고칠 것을 보고한다:
   - 졸업대장: 건명 'YYYY학년도 제N회 졸업대장', 학년도와 졸업일(생산년도)이 맞는지, NEIS 출력 → 비전자 등록 원본(5.1).
   - 시험기록물: 평가원안·답안지 건명, 답안지는 학년·반별 1권 = 1건(5.2).
   - 학교폭력: 하나의 학교폭력 관련 단위과제에 일관 편철(5.4). 학교연혁지는 '학교역사기록물관리'(5.3).
   - 보건일지·급식일지·CP/CCP 일지: 학년도 마감 때 출력해 비전자 등록(5.5·5.6).
   - 동의서·신청서·설문지: 개인정보 보호법으로 파기하지 않고 공공기록물법 절차(5.7). 학교는 자체 폐기 불가(4.2.8). 수기 출석부도 기록물(해석례).
   - 건명에 개인정보(가린 이름, 학년-반+이름, 주민번호·휴대전화 형태): 수정 이력을 남기고 건명 수정(해석례 7).
3. '이관 시기' 시트: 비전자는 보존기간 기산일부터 2년 범위, K-에듀파인 전자기록물은 1년 단위, 민원·소송 등 연장은 기산일부터 10년 범위, 비치기록물은 사유가 끝나면(4.2.6).
4. '생산현황 유형(표 1)': 문서·회의록·시청각(졸업앨범 포함)·행정박물·간행물(학교○○년사·교지·규정집) 건수 추정, 5월 31일 통보.
5. 문서고 대장 3종(보존문서기록대장·반출반입대장·출입대장) 빈 서식. 문서고 환경은 20±2℃·50±5%·100~300lux, 이중잠금·제한구역(4.2.10) — 온습도 기록이 있으면 stack-environment로 본다.
6. 폐교: `--closing 2027-02-28 --successor "가상초등학교"`(승계학교 없으면 비움) → '폐교 인계 계획'(상자 00001~, 인수 기관, 공인은 기록관으로)·'폐교 체크리스트'(목록 → 실사·정리 → 계획 → 포장·이송 → K-에듀파인 과제카드 인계 → 생산 당시 학교명·기관코드 유지). 일반 기관 폐지는 agency-closure.

하지 않는 것: 보존기간·폐기·공개 결정, NEIS 학교생활기록부 정정(「학교생활기록 작성 및 관리지침」), 학교폭력 조치사항 처리.
참고 해석례: 사립유치원은 공공기관(유치원생활기록부 포함), 공립어린이집은 적용 대상 아님, 스캔해 첨부해도 비전자 증빙 원본은 보존, 붙임에 암호 설정 금지.
